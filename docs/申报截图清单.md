# 大模型安全攻防与可信评测虚拟仿真实验申报截图清单

## 使用说明

本目录截图于 2026 年 10 月 14 日从本地运行的申报演示版采集，统一使用 1440 × 1000 或 1440 × 1100 的桌面视口。截图中的模型响应均为预设案例虚拟仿真输出；综合结果、能力画像和教师看板中的学生与统计内容均为教学演示数据，不得作为真实教学人数、教学成绩或应用成效证明。

正式填报时，应优先选择能够形成“实验定位—实质操作—不同反馈—防御复测—过程评价—能力画像—实验报告”证据链的图片。同一份申报书、视频和平台填报应保持项目名称、指标、分数和数据性质表述一致。

## 视频画面建议

### 3分钟项目简介视频

按截图 1 → 3 → 4/5/6 → 8 → 9 → 11 的顺序组织，突出项目定位、实质操作、攻防闭环和评价结果。

### 5分钟教学引导视频

从实验准备页开始，演示一次“选择—反馈—确认—进入下一步”的完整操作，再快速展示越狱、幻觉、注入和防御复测，最后进入结果和报告页面。

## 重新采集注意事项

- 使用 Chrome 或 Microsoft Edge 最新稳定版。
- 建议视口宽度不低于 1366 像素，浏览器缩放为 100%。
- 截图前关闭无关标签页、通知和扩展浮层。
- 演示结果页必须保留“教学演示结果”提示。
- 教师看板必须保留“教学演示数据，不代表真实教学人数或成效”提示。
- 如果改动评分公式或仿真参数，应重新采集截图 8—12，保证指标与报告一致。
